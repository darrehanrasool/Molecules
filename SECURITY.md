## Reporting a Vulnerability

We take the security and integrity of our research software, API microservices, and chemical data assets seriously.

If you believe you have found a security vulnerability in this repository, please **do not** open a public GitHub issue. Instead, report it privately to the project research maintainers:

- **Lead Maintainer**: Dar Rehan Rasool ([@darrehanrasool](https://github.com/darrehanrasool))
- **Email**: `darrehanrasool@gmail.com`
- **Academic Affiliation**: Centre for Artificial Intelligence, Islamic University of Science and Technology (IUST), Kashmir, India

### When reporting, please provide:
1. A clear description of the vulnerability and its potential impact.
2. Step-by-step instructions or proof-of-concept code to reproduce the issue.
3. Affected components (e.g. FastAPI backend endpoint, Streamlit dashboard, data parsing pipeline).
4. Any proposed fixes or remediations if known.

### Response & Disclosure Policy:
- We acknowledge vulnerability reports within **48 hours**.
- We will evaluate the report, verify the issue, and provide an estimated timeline for remediation.
- Critical vulnerabilities will receive immediate patch priority and a public advisory release once resolved.
- We kindly request that you follow coordinated disclosure practices and avoid sharing vulnerability details publicly until a patched release is published.
