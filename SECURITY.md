# Security Policy

| Version | Supported          |

## Reporting a Vulnerability

If you discover a security vulnerability within this repository, please report it privately to the maintainers:
- **Email**: `darrehanrasool@gmail.com`

Please provide a detailed description of the vulnerability, steps to reproduce, and any relevant logs or code snippets. We will respond promptly.
