# Visualizations Directory

- `data_exploration/`: Distribution plots of precursor m/z, adduct frequencies, and peak multiplicities.
- `spectral_analysis/`: Mirror plots and head-to-head fragmentation spectrum comparisons.
- `training/`: Training and validation loss curves, learning rate dynamics.
- `validation/`: MRR@25 ranking distributions and top-k accuracy curves.
- `comparisons/`: Benchmark bar charts comparing classical baselines against deep neural retrieval.
